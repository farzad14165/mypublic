# mypublic
Here you can find a python code for LLM based chat bot using hugging face and Mistral model ("mistralai/Mistral-7B-Instruct-v0.2")
Just create a key.py file in the same directory and put your huggingface key there as key="...". Then run this command: "nohup streamlit run your_app.py --server.port 8501 &". This runs the py file in the background of the terminal.
